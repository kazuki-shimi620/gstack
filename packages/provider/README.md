# @gstack/provider

gstack Providerが実装するProvider非依存contract、Manifest、Registry、Runtime境界を提供します。

## Status

開発中であり、まだnpmへ公開していません。Node.js 24以上のESM環境を対象とします。

具体的なProvider API、credential、Schema解析、CLI処理はこのPackageへ含めません。Provider実装規則は[PROVIDER.md](../../docs/PROVIDER.md)を参照してください。
