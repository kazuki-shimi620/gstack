# @gstack/core

Schema読込からApplication Model、Validation、Migration／Generation／Providerのread APIを提供するgstackの公式Core APIです。

## Status

開発中であり、まだnpmへ公開していません。Node.js 24以上のESM環境を対象とします。

Coreは具体Providerへ依存せず、構造化結果を返します。Google固有処理、CLI表示、MCP protocol処理は含みません。Architecture invariantsは[ARCHITECTURE.md](../../docs/ARCHITECTURE.md)を参照してください。
