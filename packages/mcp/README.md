# @gstack/mcp

gstack ProjectをAI Agentから安全に参照する公式stdio MCP serverです。

## Status

開発中であり、まだnpmへ公開していません。Node.js 24以上のESM環境を対象とします。

Packageの`gstack-mcp` binをMCP hostから起動します。MVP surfaceはread／validate専用で、Apply、Rollback、Deploy、Remove、Deleteを公開しません。設定例とTool一覧は[MCP仕様](../../docs/MCP.md)を参照してください。
